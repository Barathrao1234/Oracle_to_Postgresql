### 2. Oracle Built-in Functions

Replace Oracle-specific functions with PostgreSQL-compatible equivalents when their behavior is known.

Examples:

```sql
NVL(column_name, value)
```

→

```sql
COALESCE(column_name, value)
```

and:

```sql
DECODE(...)
```

→ appropriate PostgreSQL `CASE` logic.

Verify NULL behavior, data types, implicit conversions, and evaluation semantics before replacing a function.

### 4. Oracle Custom Types and Collections

Pay special attention to:

### 7. ROWNUM and Pagination

Do not blindly replace `ROWNUM` with `LIMIT`.

Determine the query level where `ROWNUM` is applied.

For example:

```sql

FROM (
    SELECT ...
    FROM ...
    ORDER BY ...
)
WHERE ROWNUM <= :limitRows
```

must preserve the original ordering and row-limiting semantics.

Preserve bind parameters such as:

```sql
:limitRows
```

Do not replace bind parameters with invented values.
